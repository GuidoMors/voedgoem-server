# Scoring

When the game ends, each player counts the unit squares of the pieces they did **not** place.

## Basic Scoring (standard)
- Count the total number of squares across all of your unplaced pieces.
- **The player with the fewest squares remaining wins.**
- A player who placed all 21 pieces has 0 squares remaining, which is the best possible result.

Example: If a player has an unplaced I2 (2 squares) and an unplaced T5 (5 squares), their remaining total is 7.

## Advanced Scoring (optional, widely used)
Each player's score is calculated as:

1. Start at 0.
2. Subtract 1 point for every unit square left unplaced.
3. If the player placed **all 21 pieces**, add **+15** bonus points.
4. If the player placed all 21 pieces **and the last piece they placed was the monomino (the 1-square piece)**, add a further **+5** bonus points (for a total bonus of +20).

**The player with the highest score wins.**

Examples:
- Placed all pieces, last was the monomino: 0 + 15 + 5 = **+20**
- Placed all pieces, last was another piece: 0 + 15 = **+15**
- 10 squares left: **-10**
- All 89 squares left: **-89**

## Which Method to Use
- Use **basic scoring** unless advanced scoring is chosen before the game begins.
- The method must be agreed before play starts and does not change during a game.

## Ties
- With either method, if two or more players have the same score, they **share the victory** (tie).
- Optional tiebreaker if a single winner is wanted (agreed before the game): among tied players, the player whose largest unplaced piece is smaller wins. If still tied, the tie stands.
